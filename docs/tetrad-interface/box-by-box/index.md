# Box by Box

[//]: # (## Overview)

This section gives in-depth coverage of the Tetrad graphical user interface (GUI), describing the purpose and
usage of each box in the left-hand sidebar. The boxes are documented in the order they appear in the
palette. The Latent Structure box, which was removed in October 2026, is last; its page is kept because
sessions saved before the change still contain that box.
